## AVR 28-Pin Test Board

The board can use a 300/400 mil ZIF socket for Mega AVR devices in dual inline package, eg. avr64dd28. All dx, ex 28-pin DIL devices have identical pin-out. The board provides:
- USB-C 12 Mbit interface
- dual UART interface for simultaneous serial and UPDI access.
- 3.3v power supply from USB
- reset circuitry compatible with Arduino IDE and HV UPDI
- status LED on port PA6
- user switch on port PA7
- 32768 Hz crystal connected to PF0/PF1
